# Terraform AWS EC2 Web Server

Automated deployment of an Apache web server on AWS EC2 using Terraform (Infrastructure as Code).

## What it creates
- RSA key pair (generated by Terraform)
- Security group (ports 22, 80, 443)
- EC2 instance (Amazon Linux 2023, t3.micro) in the default VPC
- Apache httpd, with the website cloned from GitHub via user_data

## How to run
terraform init
terraform plan
terraform apply

## Output
Public IP of the web server (open it in a browser)

## Clean up
terraform destroy
